# Claude Code Design Skills — Project Usage

This repository has project-local Claude Code design skills in `.claude/skills/`.

## Installed skills

Julian Oczkowski designer workflow:

- `design-flow` — guided end-to-end process
- `grill-me` — requirements interrogation
- `design-brief` — codebase-aware brief creation
- `information-architecture` — navigation / hierarchy / flows
- `design-tokens` — token system extension/generation
- `brief-to-tasks` — ordered implementation checklist
- `frontend-design` — implementation with named aesthetic philosophy
- `design-review` — critique against brief, ideally with screenshots

Anthropic anti-slop frontend skill:

- `anthropic-frontend-design` — compact visual-design guidance for focused UI work

## Recommended usage for this repo

Use `anthropic-frontend-design` for small UI polish.

Use `design-flow` or the Julian phase skills for larger redesign/features. Start from:

- `.design/collective-portfolio/DESIGN_BRIEF.md`
- `.design/collective-portfolio/TASKS.md`

Hard constraints for ADDD work:

- Foreground ADDD as collective, not Artur as solo founder.
- Keep Noir et Or ADDD pixel/wordmark unless Arturo asks to switch.
- Dark organic editorial + Nothing-like mono/dot accents.
- Avoid generic SaaS landing chrome, warm amber glow, smooth sterile perfection, and pasted-in AI decoration.
- Keep public design focused on current collective direction; older themes stay archived unless explicitly requested.
